# AI Tutor

Uses AI to put together a daily plan, help students prepare, guide them through homework, and assist with assignments — without ghostwriting the take-home.

This repo is the **source of truth for product docs**. The live app is built in Floot.

## Product one-liner

A focused daily tutor that turns Schoology files and tonight's work into a sequenced plan, short guided sessions, and a parent-visible close-the-loop.

## Build rule

Spec first. Do not ship a feature that is not in the docs. If we want it, we write it into the spec, then the plan, then the code.
