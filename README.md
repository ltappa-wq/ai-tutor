# AI Tutor

Uses AI to put together a daily plan, help students prepare, guide them through homework, and assist with assignments — without ghostwriting the take-home.

This repo is the **source of truth for product docs**. The live app is built in Floot.

## Documents

| Doc | Purpose |

| [docs/SPEC.md](docs/SPEC.md) | Product requirements, user flows, non-goals, constraints |
| [docs/FEATURES.md](docs/FEATURES.md) | Competitor map + P0/P1/P2/Out include list |
| [docs/PLAN.md](docs/PLAN.md) | Spec-driven build phases for Floot |
| [docs/DATA-MODEL.md](docs/DATA-MODEL.md) | Entities and relationships for v1 |

## Product one-liner

A focused daily tutor that turns "I have homework and I don't know where to start" into a sequenced plan, short guided sessions, and a parent-visible close-the-loop.

## Build rule

Spec first. Do not ship a feature that is not in `SPEC.md` / `FEATURES.md`. If we want it, we write it into the spec, then the plan, then the code.
